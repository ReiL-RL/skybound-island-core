# SkyBound Island Core

Аддон для **SkyBound v2**, добавляющий интерактивные блоки-ядра на острова. Игроки взаимодействуют с ядрами, чтобы получать XP острова, активировать бустеры или покупать улучшения через GUI.

## Типы ядер

Плагин содержит **3 ядра**, каждое со своей механикой:

| Ядро | ID | Описание |
|------|-----|----------|
| **Ядро Опыта** | `xp_core` | Сдавай ценные ресурсы для получения XP острова |
| **Ядро Бустера** | `booster_core` | Активируй бустеры через GUI выбора |
| **Ядро Улучшений** | `upgrade_core` | Покупай улучшения острова через GUI выбора |

### Ядро Опыта (`xp_core`)
Игрок кликает ПКМ по ядру, открывается GUI для сдачи ресурсов. Предметы конвертируются в XP острова.

### Ядро Бустера (`booster_core`)
При взаимодействии открывается **GUI выбора бустера**. Игрок выбирает нужный бустер и активирует его.

### Ядро Улучшений (`upgrade_core`)
При взаимодействии открывается **GUI выбора улучшения**. Игрок выбирает улучшение и покупает следующий уровень.

## Улучшения (8 штук)

| Улучшение | ID | Описание |
|-----------|-----|----------|
| Размер острова | `island_size` | Увеличивает границы острова |
| Лимит мобов | `mob_limit` | Увеличивает максимум мобов на острове |
| Скорость генератора | `generator_speed` | Ускоряет работу генератора руд |
| Слоты варпов | `warp_slots` | Увеличивает количество доступных варпов |
| Лимит участников | `member_limit` | Увеличивает максимум участников команды |
| Автопродажа | `autosell` | Автоматическая продажа предметов из генератора |
| Полёт на острове | `island_flight` | Временный полёт на острове (ежедневный) |
| Хранилище острова | `island_storage` | Увеличивает размер общего хранилища |

## Бустеры (4 штуки)

| Бустер | ID | Описание |
|--------|-----|----------|
| Буст XP | `xp_boost` | Увеличивает получаемый XP |
| Буст генератора | `generator_boost` | Ускоряет генерацию руд |
| Буст продажи | `sell_boost` | Увеличивает цену продажи предметов |
| Буст удачи | `luck_boost` | Увеличивает шанс редких руд в генераторе |

## Автоматическое размещение

Ядра **автоматически выдаются** игроку при:
- Создании нового острова
- Регенерации острова

Игрок получает все 3 ядра и может разместить их на своём острове.

## Интеграции

| Плагин | Тип | Описание |
|--------|-----|----------|
| **SkyBound** | Обязательный | Основной плагин SkyBound v2 |
| **SopLib** | Обязательный | Библиотека утилит |
| **SopCustomBlocks** | Опциональный | Кастомные модели блоков для ядер |
| **SopItemsCreator** | Опциональный | Кастомные предметы для рецептов и наград |

## Команды

| Команда | Описание | Право |
|---------|----------|-------|
| `/islandcore place <type>` | Разместить ядро указанного типа | `islandcore.admin` |
| `/islandcore remove` | Удалить ядро (на которое смотришь) | `islandcore.admin` |
| `/islandcore list` | Список всех типов ядер | `islandcore.admin` |
| `/islandcore reload` | Перезагрузить конфигурацию | `islandcore.admin` |

Алиас: `/icore`

## Права

| Право | Описание | По умолчанию |
|-------|----------|--------------|
| `islandcore.admin` | Доступ к админ-командам | op |
| `islandcore.use` | Использование ядер | true |

## Конфигурация

### config.yml

```yaml
# Блок-заглушка если SopCustomBlocks недоступен
fallback-block: BEACON

# Авто-выдача ядер при создании/регенерации острова
auto-give-on-create: true

# Частицы над ядрами
particles:
  enabled: true
  type: END_ROD
  count: 3
  interval-ticks: 10
```

### cores.yml — Определение типов ядер

Каждый тип ядра определяет:
- `display-name` — отображаемое имя
- `description` — описание в GUI
- `custom-block` — ID кастомного блока (SopCustomBlocks)
- `gui-title` — заголовок GUI
- `gui-size` — размер GUI (кратно 9)
- `items` — принимаемые предметы и их XP-стоимость (для `xp_core`)
- `action` — действие при сдаче (ADD_ISLAND_XP, SELECT_BOOSTER, SELECT_UPGRADE)

## Как работает

1. При создании/регенерации острова игрок получает 3 ядра в инвентарь
2. Игрок размещает ядра на острове (ПКМ по блоку)
3. При взаимодействии с ядром открывается соответствующий GUI:
   - **xp_core**: GUI сдачи ресурсов → XP
   - **booster_core**: GUI выбора бустера → активация
   - **upgrade_core**: GUI выбора улучшения → покупка
